# phase46_rfcw_wake_treference

Focused Action 6 regression for wake-bearing `RFCW` cavities with explicit
nonzero `T_REFERENCE`.  The lattice exercises matrix-method and multi-kick
collective slices with longitudinal/transverse wake columns, fixed-bin filtered
LSC kicks, smoothing/interpolation, deterministic offsets, focusing,
`CHANGE_P0`, and `WAKES_AT_END=0|1`.
