# phase44_rfcw_single_wake_planes

Focused Action 6 regression for serial/local wake-bearing `RFCW` cavities with
only one wake family active at a time.  The lattice exercises longitudinal-only
and transverse-only collective kicks across matrix-method and kick-method
`RFCW` sections with smoothing/interpolation, deterministic offsets, focusing,
`CHANGE_P0`, and `WAKES_AT_END=0|1`.
