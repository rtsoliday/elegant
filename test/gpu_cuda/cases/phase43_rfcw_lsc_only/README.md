# phase43_rfcw_lsc_only

Focused Action 6 regression for serial/local `RFCW` cavities with guarded
fixed-bin LSC kicks and no active longitudinal/transverse wake columns.  The
lattice exercises matrix-method and kick-method collective slices with
deterministic offsets, focusing, `CHANGE_P0`, filtered LSC bins, and
`WAKES_AT_END=0|1`.
