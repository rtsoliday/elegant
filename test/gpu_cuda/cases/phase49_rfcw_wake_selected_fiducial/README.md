# phase49_rfcw_wake_selected_fiducial

Focused Action 6 regression for serial/local selected-bunch RF fiducialization
inside guarded wake-bearing `RFCW` slices.  The case creates a two-bunch SDDS
beam, selects bunch 1, and exercises selected-bunch `TMEAN` and `PMAXIMUM`
phase setup across matrix-method and multi-kick wake/LSC cavities.
