# phase45_rf_kick_treference

Focused Action 6 regression for RF-only kick-method `RFCA` and `RFCW`
cavities with explicit nonzero `T_REFERENCE`.  The lattice exercises
multi-kick RFCA/RFCW section tracking with deterministic offsets, entrance/exit
focusing, `CHANGE_P0`, and no-op RFCW `WAKES_AT_END=1`.
