# phase47_rf_selected_tmean_fiducial

Focused Action 6 regression for serial/local bunch-restricted `TMEAN`
fiducialization.  The case creates a two-bunch SDDS beam, selects bunch 1 for
RF fiducialization, and exercises zero-length, matrix-method, and kick-method
`RFCA` plus RF-only matrix-method and kick-method `RFCW` cavities.
