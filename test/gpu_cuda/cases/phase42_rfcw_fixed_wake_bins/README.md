# phase42_rfcw_fixed_wake_bins

Focused Action 6 regression for serial/local wake-bearing `RFCW` with fixed
longitudinal/transverse wake bins.  The lattice exercises the guarded
matrix-method and kick-method collective slices with `N_BINS=1024`,
smoothing/interpolation, deterministic offsets, focusing, `CHANGE_P0`, and
`WAKES_AT_END=0|1`.
